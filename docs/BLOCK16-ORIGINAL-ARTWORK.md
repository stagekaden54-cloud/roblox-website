# BLOCK16 original artwork pack

## Purpose
This pack introduces a small set of independently authored BLOCK16 vector assets. It is intended to give the project a visual identity that does not depend on the legacy membership images.

## Included assets
- `vercel-frontend/assets/block16-original-mark.svg` — geometric primary mark.
- `vercel-frontend/assets/block16-original-icon.svg` — compact square icon.
- `vercel-frontend/assets/block16-original-builder-badge.svg` — creator/builder badge concept.
- `vercel-frontend/brand-artwork.html` and `brand-artwork.css` — static preview page at `/brand-artwork.html`.

## Provenance
These SVG files are hand-authored vector markup made from basic geometric shapes, gradients, and strokes for BLOCK16. They do not embed, trace, recolor, or otherwise reuse the three legacy membership PNGs. No AI image-generation tools or generated image assets were used.

The design language intentionally uses a broad classic-era blue, beveled interface aesthetic. The shapes and compositions in this pack are original BLOCK16 concepts, not claims of ownership over any broader visual style.

## Scope and limitations
- These are concept assets, not registered trademarks or a legal clearance opinion.
- The builder badge does not create an actual membership tier, account status, or creator entitlement.
- The preview page is static and does not connect to authentication, payments, or backend services.
- The existing legacy-derived membership artwork remains separately documented in `vercel-frontend/README.md` and is not replaced by this pack.
